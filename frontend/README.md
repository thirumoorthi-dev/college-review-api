# College Review System - React Frontend

Modern React application built with **TypeScript, Tailwind CSS v4, Redux Toolkit (RTK Query), and React Hook Form** for discovering and reviewing Tamil Nadu colleges.

## Features

- **Live Directory & Search:** Filter by city (Chennai, Coimbatore, Madurai, Trichy), search by name, and sort by highest rated.
- **Dynamic Aggregation Ratings:** Immediate feedback with stars, ratings, and rating breakdown charts.
- **Review Submission:** React Hook Form with interactive 1-5 star picker, title, and comments.
- **One-Click Demo Profiles:** Instant evaluator sign-in for Student, Teacher, and Admin personas.
- **Admin Management:** Add new colleges dialog for Admin users.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Run local development server (port 3000, proxies to backend:5000)
npm run dev

# 3. Build for production
npm run build
```
